買取価格の取得ボタン

買取wiki と 森森買取は、GitHub のサーバーからの取得を受け付けません。
そこで、あなたのブラウザから取得して GitHub に保存するボタン（ブックマーク）を使います。

① ボタンをブックマークバーに登録（初回だけ）

  1. ブックマークバーが見えていなければ Ctrl＋Shift＋B（Macは ⌘＋Shift＋B）で表示します。
  2. 下の赤いボタンを、マウスでブックマークバーまでドラッグします（クリックではありません）。

買取価格を取得

準備中…

リポジトリ名を変える場合

② GitHub の合鍵（トークン）を作る（初回だけ）

ボタンが GitHub にデータを保存するための鍵です。このリポジトリだけに権限を絞って作ります。

  1. 合鍵の作成ページを開きます（GitHubにログインした状態で）。
  2. Token name：kaitori-tool など何でも。
  3. Expiration：Custom を選び、1年後の日付にします（期限が切れたら作り直し）。
  4. Repository access：Only select repositories を選び、kaitori-tool を選択。
  5. Permissions →「Add permissions」（または Repository permissions）で次の2つを Read and write にします。
    • Contents（データの保存）
    • Actions（Yahoo照合の自動開始）
  6. 一番下の Generate token を押し、表示された github_pat_… で始まる文字列をコピーします。
    この画面を閉じると二度と表示されません。分からなくなったら作り直せばOKです。

③ 使い方（更新したいとき）

  1. 買取wiki か 森森買取 のページを開きます（どのページでもOK）。
  2. ブックマークバーの「買取価格を取得」を押します。
  3. 初回だけ合鍵を聞かれるので、②でコピーした文字列を貼り付けて OK。
  4. 右上に進み具合が出ます。終わるまでタブを閉じないでください（買取wikiは1〜3分、森森買取はサイトの制限を避けるためゆっくり取るので20〜30分）。
  5. 「完了」と出たら、Yahoo照合が自動で始まります。30〜60分ほどで一覧に反映されます。

買取価格は押した時点のものです。仕入れを検討する日に、両サイトで1回ずつ押してください。一覧の上部に各サイトの取得日時が出ます。

困ったとき

・「合鍵が無効」「権限がありません」と出た：合鍵の期限切れか、権限の付け忘れです。②をやり直し、もう一度ボタンを押すと合鍵を聞かれます。

・「○件だけでした…保存していません」と出た：サイトの作りが変わった可能性があります。古いデータはそのまま残ります。

・合鍵を消したいとき：GitHub の 合鍵一覧 から削除できます。
