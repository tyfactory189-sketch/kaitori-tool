自動取得の拡張機能（Chrome）

買取wiki（iPhone・iPad・Mac 等の容量・色ごとの価格を含む）と森森買取を、決まった時刻に自動で取得して GitHub に保存し、Yahoo照合を始めます。さらに、利益が出そうな Yahoo の出品はログイン中のあなたの会員条件（LYPプレミアム・ランク・PayPay・キャンペーン・上限）での付与ポイントを確認します。PC と Chrome が起動している間だけ動きます。

① PC の準備（初回だけ）

  1. スタート →「設定」→「システム」→「電源」で、スリープを「なし」にする。
  2. Chrome の「︙」→「設定」→「システム」で、「Google Chrome を閉じた際にバックグラウンド アプリの処理を続行する」をオンにする。
  3. Windows＋R →「shell:startup」→ Enter。開いたフォルダにデスクトップの Chrome のショートカットをコピー（再起動後も Chrome が自動で立ち上がるように）。
  4. その Chrome で Yahoo! JAPAN にログインしておく（プレミアム会員の ID で）。

② 拡張機能を入れる（初回だけ・5分）

  1. 拡張機能をダウンロード
  2. ダウンロードした kaitori-extension.zip を右クリック →「すべて展開」。展開したフォルダは消したり移動したりしない場所（例：ドキュメント）に置きます。
  3. Chrome のアドレス欄に chrome://extensions と入力して Enter。
  4. 右上の「デベロッパー モード」をオン。
  5. 左上の「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダ（中に manifest.json があるフォルダ）を選ぶ。
  6. 「買取差益チェッカー 自動取得」が表示されたら成功。アドレス欄右のパズルのアイコン → 📌 でツールバーに固定しておくと便利です。

③ 設定する（初回だけ）

  1. ツールバーの拡張機能アイコン →「設定（合鍵・時刻）」を開く。
  2. 「GitHub の合鍵」に、買取価格を取得ボタン用に作った github_pat_… を貼り付け。
  3. 時刻は最初から 11:00, 14:00, 20:00 になっています。変えたいときはここで。
  4. 「保存」→「合鍵も確認できました ✓」と出れば完了。
  5. 試しに拡張機能アイコン →「今すぐ取得する」。30〜40分ほどで「前回は成功」と表示されます（その間 Chrome は閉じないでください）。

困ったとき

・「合鍵が無効」：合鍵の期限切れなど。新しく作って設定画面で入れ直してください。

・「取得できないページが続きました」：サイト側の一時的な制限です。次の時刻に自動でやり直します。

・拡張機能を更新したいとき：新しい zip で展開したフォルダを置き換え、chrome://extensions の拡張機能の「⟳（再読み込み）」を押します。設定は残ります。

・手動のブックマーク「買取価格を取得」も、これまでどおり使えます。
